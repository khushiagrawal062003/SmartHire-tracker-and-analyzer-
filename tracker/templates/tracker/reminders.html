Multithreaded Execution

SmartHire features a **Multithreaded Reminder Scheduler** module. When you click **"Trigger Reminder Thread"** or when the background checks run:

  • A background worker thread is spawned immediately, separate from the main Django server thread.
  • It queries MongoDB for all applications having a **deadline** equal to today or in the past.
  • It prints notifications to your console representing an SMS/Email service client.
  • This allows fast HTTP requests without blocking your UI while sending notifications.
